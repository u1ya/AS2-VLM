# Первый физический тест AS2

Движение из VLM и браузерного демо по-прежнему заблокировано.
Перед тестом необходимы оператор со штатным пультом, проверенная остановка
по инструкции AS2, свободный ровный пол, отсутствие людей и хрупких
предметов в зоне движения и достаточный запас Ethernet-кабеля. Не подходить
к ногам работающего робота и не пытаться удерживать его руками.

Отключение Ethernet, Ctrl+C и закрытие терминала НЕ являются гарантированной
аварийной остановкой. Поведение при потере связи на этой прошивке не проверено.
StopMove зависит от сети, WSL, SDK-сервиса и ОС; это программный запрос,
не аппаратный E-stop. Нужен независимый штатный способ остановки.

## Подготовленный канал программной остановки

Отдельная утилита содержит только вызов StopMove, без Move, StandDown,
Damp и смены владельца управления. Она не запускается из демо или VLM.
В Ubuntu из корня проекта открыть отдельный терминал:

```bash
./build/as2-probe/as2_stop_only eth1 --ready
```

Через 2 секунды DDS инициализирован локально; это ещё не подтверждение
доставки StopMove. Нажатие Enter или ввод STOP отправляет один запрос.
Код 0 означает подтверждение API, но остановку тела нужно проверить визуально.
При ошибке использовать штатный пульт. Q завершает утилиту без нового запроса.
Не запускать несколько источников команд движения или второй робот в том же DDS domain.

Одноразовый вариант (при холодном старте есть задержка инициализации DDS):

```bash
./build/as2-probe/as2_stop_only eth1 --stop
```

Не использовать cold-start команду как единственную защиту. StopMove должен
быть проверен оператором до первого движения, когда робот уже неподвижен
и зона безопасна. Утилита подготовлена и собрана; физический StopMove
не отправлялся автоматически при подготовке.

## Движение

SportClient.Move задаёт скорость, а не число шагов ног и не точную дистанцию.
Для первого опыта нужен отдельно ограниченный по времени малый импульс,
остановка по окончании и при ошибке, плюс контроль оператора с пультом.
Сам по себе локальный таймер не гарантирует остановку при зависании ОС
или потере сети. Не начинать с команды пройти метр и не считать StopMove
или отключение кабеля независимой аварийной защитой.

## Подготовленный ручной импульс

Отдельный as2_forward_pulse не связан с VLM, HTTP или симуляцией.
Из корня проекта в Ubuntu:

```bash
./build/as2-probe/as2_forward_pulse eth1 --execute
```

Программа ждёт точную строку FORWARD. Любой другой ввод или EOF отменяет
тест до инициализации SDK. Вводить подтверждение только с готовым штатным
контроллером остановки, свободным ровным полом и достаточным запасом кабеля.
После ввода проверяются GetState (NORMAL_WALK, process_state=0) и StopMove;
при неуспехе Move не вызывается. Режим/поза/владелец управления не меняются.

Команда Move задаёт +0.1 м/с по x, ноль по y и yaw. Номинальная длительность
импульса 300 мс; затем выполняется StopMove. На ошибку Move, исключение
или обработанный SIGINT/SIGTERM предусмотрен best-effort StopMove.
При неуспехе остановки предусмотрено до трёх попыток, но гарантий доставки нет.
Вызов SDK может задержаться; это не жёсткая граница времени движения.
Зависание WSL, SIGKILL, обрыв кабеля и потеря питания обходят локальную защиту.
Поэтому независимый штатный способ остановки обязателен.

Реальная длина перемещения и число шагов ног не измеряются и не гарантируются.
Не повторять тест автоматически, если робот не сделал ожидаемое движение.
При любом неожиданном движении использовать штатный контроллер остановки.
На этапе подготовки собраны executable и fake-client тесты, но физический
Move не отправлялся.

Проверка политики без оборудования:

```bash
ctest --test-dir build/as2-probe --output-on-failure
```

## Ручной метрический тест

Добавлен отдельный as2_walk_meter, не связанный с VLM или HTTP. Его физический
запуск пока не выполнялся. Цель — 1 метр по оценке одометрии с допуском 2 см,
а не метр за секунду. Скорость ограничена 0.15 м/с и снижается перед целью;
ожидаемое время порядка 7-10 секунд, ограничение по времени — 12 секунд.
Погрешность одометрии и выбег после StopMove не откалиброваны: точная
дистанция и остановка без превышения цели не гарантируются.

Read-only проверка:

```bash
./build/as2-probe/as2_walk_meter eth1 --observe
```

Проверено на AS2: 57 сообщений за 3 секунды, mode=3, error=0, предзапусковая
проверка пройдена без Move/StopMove. Обнаружено, что stamp в сообщениях этой
прошивки равен нулю. Поэтому свежесть проверяется по монотонному времени
фактического приёма сообщений DDS и локальной последовательности доставки,
а не по несуществующей метке производителя. Если в другой прошивке source
stamp предоставляется, дополнительно контролируется его рост/сброс.
Наличие свежих сообщений не доказывает истинность координат или отсутствие
проскальзывания. Дополнительно проверяются прогресс и непрерывность позиции.

Только после отдельной готовности оператора:

```bash
./build/as2-probe/as2_walk_meter eth1 --execute
```

Точная строка METER подтверждает физическое движение. До этого SDK не
инициализируется; любой другой ввод отменяет тест. Требуется свободный ровный
коридор с запасом места, свободный кабель и готовый штатный контроллер
остановки у оператора. Датчики препятствий в этот тест НЕ подключены.

Условия best-effort остановки: данные старше 300 мс, отсутствие хотя бы
2 см прогресса за 2 с, превышение 12 с, скачок позиции более 7 см между
проверками, отклонение курса более 0.25 рад, боковое отклонение более 12 см,
заметный обратный ход, изменение режима/ошибка состояния, опасный наклон,
вертикальное отклонение или скорость, ошибка API и обработанное прерывание.
Проверка на старте требует почти неподвижного состояния и подтверждения
StopMove. Локальная логика не заменяет watchdog на роботе: зависание ОС,
потеря сети или принудительное убийство процесса могут помешать остановке.

После StopMove утилита дополнительно читает телеметрию и сообщает итоговый
прогресс по одометрии и результат проверки малой скорости. Это не заменяет
наблюдение оператора. Тесты политики C++ не используют робот; реальный
метрический проезд ещё требует отдельного подтверждения и проверки.

Во время метрического теста Move обновляется циклически. Отдельный
as2_stop_only не отменяет этот цикл: следующий Move может перекрыть
его StopMove. Поэтому нельзя считать Enter в другом терминале остановкой
метрического теста. Для отмены нужен Ctrl+C в терминале самого теста
(с best-effort обработкой) или независимая штатная остановка контроллером.
Кнопка остановки в браузерной симуляции физическим тестом не управляет.

## Настройка порога вертикальной скорости

Следующая подтверждённая попытка остановилась по vertical_speed_limit:
vz=0.187889 м/с при пороге 0.15 м/с. Итоговый прогресс по одометрии
0.04043 м, StopMove=0, telemetry_stationary=1. Оператор наблюдал начало
ходьбы с немедленной остановкой.

По запросу оператора порог abs(vz) увеличен до 0.25 м/с. Это предварительная,
не валидированная на роботе настройка, а не гарантия безопасности или
прохождения метра. Остальные ограничения, включая высоту, наклон,
горизонтальную скорость и свежесть данных, сохранены. Изменение порога
само по себе не запускает движение. Тесты проверяют обе полярности,
границу 0.25 и остановку при 0.2501 м/с.

При следующей попытке зарегистрировано vz=0.276612 м/с: защита 0.25 м/с
остановила тест, итоговый прогресс 0.03172 м, StopMove=0,
telemetry_stationary=1. Цель 1 м не достигнута.

После этого по запросу оператора текущий порог abs(vz) установлен в 0.5 м/с.
Этот предел не валидирован на роботе и не считается гарантированно
безопасным. Командная скорость вперёд по-прежнему ограничена 0.15 м/с;
все остальные проверки сохранены. Проверки кода охватывают обе полярности,
границу 0.5 и остановку при 0.5001 м/с. Изменение и сборка не запускают
движение.
