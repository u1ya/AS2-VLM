# Инвентаризация AS2 EDU

Статус на 2026-10-25: проверены связь, SDK, одометрия и получение RGB-кадра.
См. [sdk_notes.md](sdk_notes.md), [camera.md](camera.md) и [RESUME.md](RESUME.md).

| Параметр | Значение |
|---|---|
| Робот | Unitree AS2 EDU, со слов владельца |
| Прошивка | Неизвестно |
| Onboard ОС / CPU / RAM | Неизвестно |
| SSH и механизм установки приложений | Неизвестно |
| SDK и руководство | Получена ссылка на официальный AS2 guide; текст статьи не загрузился. Проверены README, AS2 header и CMake официального unitree_sdk2 |
| Проверенное управление | Отдельные ручные тесты: последний проезд 0.969 м по одометрии, StopMove=0; VLM/демо не управляют роботом |
| RGB / калибровка | JPEG 1920x1080 через videohub, 4 кадра проверены; модель сенсора и калибровка неизвестны |
| LiDAR или depth / калибровка | PointCloud2 ~9.7 Гц, 81633 XYZ-точки в последнем облаке, frame=hesai_lidar; IMU и состояние поступают, error=0. Точная модель, extrinsics и depth-камера не подтверждены. См. lidar.md |
| Одометрия / IMU | sportmodestate поступает; позиция, скорость, rpy; source stamp=0, используется свежесть локального приёма |
| Внешний GPU / ОС / VRAM | На текущем ПК: Windows, NVIDIA GeForce RTX 5060 Laptop GPU, 8151 MiB VRAM (nvidia-smi). Назначение этого ПК как постоянного model server ещё не подтверждено |
| Сеть до GPU | Неизвестно |

После ответов зафиксировать источники каждого параметра. Проверку SDK, сенсоров и остановки проводить отдельными шагами. Пароли и закрытые ключи в этот документ не добавлять.

SDK публикует готовые библиотеки для Ubuntu 20.04, aarch64/x86_64 и GCC 9.4.0. Это требования/среда SDK, не подтверждение установленной ОС AS2. Текущая прошивка, onboard-среда, SSH, depth и калибровка остаются неизвестными. Проверенный RGB доступен без SSH.
