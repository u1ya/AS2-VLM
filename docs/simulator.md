# Демонстрация без робота

Из корня проекта: `./demo.ps1`, затем открыть http://127.0.0.1:8765.
Для другого порта: `./demo.ps1 -Port 8766`. Остановка сервера: Ctrl+C.

В режиме Qwen2.5-VL 3B нужен запущенный локальный Ollama с установленной моделью
(см. vlm_setup.md). Режим «Правила» не требует модели. Автоматического перехода
с Qwen на правила нет: ошибки модели показываются явно.

Проверки: `python -m unittest discover -s tests -v`.

## Что проверяется

- Текстовая инструкция превращается в проверенный план из одного-двух действий.
- Виртуальный робот поворачивается и движется по известной 2D-карте.
- Подход заканчивается в 0.65 м от точки цели.
- При столкновении с препятствием или границей движение прекращается.
- Кнопка остановки отменяет локальное воспроизведение, сброс возвращает старт.

## Ограничения

Это не симуляция динамики AS2, контактов ног или перелезания препятствий.
Координаты стены, двери и человека заданы заранее: камера и визуальное
распознавание не используются. Qwen применяется только как текстовый планировщик.
Контроллер идёт напрямую, без поиска обходного пути. Выбранные сценарии не являются
оценкой обобщения модели. Никаких команд в SDK или робот не отправляется.

Сервер слушает только 127.0.0.1, не предназначен для публикации в сети.
HTML поставляется в checkout; запуск из установленного wheel пока не поддержан.
